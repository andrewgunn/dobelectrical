# D O'Brien Electrical

Website for D O'Brien Electrical Limited, NICEIC approved electricians in Sheffield since 1990.

Plain static HTML/CSS/JS, hosted on GitHub Pages. No build step, so edit the `.html` files directly.

- `assets/css/style.css`: all styles
- `assets/js/main.js`: circuit-board hero animation, scroll effects, coverage map, project filters, quote form
- The quote form sends the enquiry via WhatsApp (07429 389961) or email (Enquiries@dobelectrical.co.uk), so no server is needed.

Preview locally: `python3 -m http.server` and open http://localhost:8000
